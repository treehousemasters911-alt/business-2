# My Website Project

This repository contains 125 files that make up my live website. 

## 📂 Project Structure

* **Main Page**: `index.html` (The homepage of the website)
* **HTML Files**: Other webpage structures and layouts.
* **CSS Folders/Files**: Styles, colors, and design layouts.
* **JavaScript Files**: Interactive elements and website logic.
* **Assets**: Images, icons, and media files used across the site.
